# Gremory
GTA 6 for cards that don't have RT or Mesh Shaders

# How
- Mesh shaders are passed to compute, shit performance n buggy but it works nevertheless
- Custom FSR4 build I made a while ago that is tailored for RDNA1 cards since the shipped xbox dll wouldn't work for obvious reasons
- RT bounces are just straight up omitted

# Performance
around 2-3 fps
